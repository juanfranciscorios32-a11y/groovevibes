Importar tareas desde Markdown

Subí un .md con formato "## Área" seguido de líneas "- [ ] tarea" (como tareas_pendientes.md). Cada área se vincula a un Proyecto en Supabase (se crea si no existe) y cada línea se agrega como Tarea de ese proyecto. Se puede correr varias veces: las tareas ya importadas no se duplican.
